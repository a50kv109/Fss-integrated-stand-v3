# STL V1 — Symmetry Transformation Lab

Автономный модуль точного матричного сопряжения операций симметрии:
$$g' = P^{-1} g P$$
для заданной пользователем матрицы перехода к новому базису $P$.

## Границы ответственности и математические ограничения

1. **Размерности:** строго $2 \times 2$ и $3 \times 3$ (`MatrixDim = 2 | 3`).
2. **Точная арифметика:** вычисления производятся в нормализованных рациональных дробях $p/q$ с промежуточными вычислениями на `BigInt` (без применения float и $\varepsilon$-допусков).
3. **Отсутствие автоматического поиска $P$:** матрица базисного перехода $P$ должна быть явно передана пользователем и быть невырожденной ($\det P \neq 0$).
4. **Изоляция от групповых аксиом:** статус `CONJUGACY_VERIFIED` подтверждает исключительно алгебраическое соотношение $g' = P^{-1} g P$ для переданного семейства матриц. Успешное сопряжение **не является доказательством** того, что набор $G$ образует математическую группу (не проверяются замкнутость, наличие обратных элементов и нейтрального элемента).
5. **Изоляция от реестра и матчера FSS:** модуль не обращается к `canonicalOperationKey`, float-геометрии `engine.ts` или классификатору Федоровских групп.

## Модель статусов (`ConjugacyStatus`)

- `CONJUGACY_VERIFIED` — сопряжение элементов вычислено успешно; все заданные критерии (`expected` и/или `pairs`) удовлетворены.
- `REFUTED` — вычисленное множество образов не совпало с `expected`, либо нарушено поэлементное соответствие в `pairs`.
- `INVALID_INPUT` — структурная или математическая ошибка входных данных (неверный тип, пустой массив, смешанные размерности, вырожденная матрица $\det P = 0$).
- `UNSUPPORTED_INPUT` — параметры выходят за рамки V1 (размерность $n \notin \{2, 3\}$ либо $|G| > \text{maxSize}$).
- `INCONCLUSIVE` — зарезервированный статус (объявлен в системе типов, но в детерминированном движке V1 фактически не возвращается).

## Примеры использования

```ts
import { ExactMatrix, verifyConjugacy } from './core/stl';
// или с использованием пути через алиас проекта:
// import { ExactMatrix, verifyConjugacy } from '@/core/stl';

// Задание генераторов и матрицы перехода
const G = [
  ExactMatrix.fromInt([[1, 0], [0, 1]]),
  ExactMatrix.fromInt([[0, -1], [1, 0]])
];
const P = ExactMatrix.fromInt([[1, 1], [0, 1]]);

// Верификация сопряжения
const result = verifyConjugacy({ G, P });
if (result.status === 'CONJUGACY_VERIFIED') {
  console.log('Образы вычислены:', result.images.map(m => m.toString()));
}
```

